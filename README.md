
# CI/CD Pipeline Automation Project

## Project Overview
This project demonstrates the implementation of a Continuous Integration and Continuous Delivery (CI/CD) pipeline using GitHub Actions and OpenShift Pipelines.

## Objectives
- Automate code checkout and dependency installation.
- Run code quality checks and unit tests.
- Build a container image.
- Deploy the application using OpenShift Pipelines.

## Technologies
- GitHub
- GitHub Actions
- Python
- Tekton
- OpenShift

## Workflow
The GitHub Actions workflow validates changes pushed to the main branch and pull requests targeting the main branch. The OpenShift pipeline automates testing, image building, and deployment.
